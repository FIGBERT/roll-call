# Morning Summary

Ideated on a post-it note on my wall, used DP3 of [DESIGN11] as an
excuse to actually make it.

## Motivations and Thoughts

Phones are great but I don't like checking mine in the morning. My
brain is totally untainted when I wake up and then I go right into my
phone and fall into Instagram and a hundred other things and all the
possibility of the new day melts away.

This is paper with a digital brain. Sort of. One experiment of many!

For more on the design, see `NOTEBOOK.pdf`.
